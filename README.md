# Курсы криптовалют к USD

## 1. Цель разработки
Создать
десктопное
приложение
на
Python(Tkinter), отображающее
текущие
курсы
популярных
криптовалют
к
доллару
США
через
открытый
API
CoinGecko.

## 2. Функциональные требования
- При
запуске
приложение
автоматически
загружает
курсы
8
криптовалют(Bitcoin, Ethereum, Tether, BNB, Solana, XRP, Cardano, Dogecoin).
- Отображение
данных
в
виде
таблицы: «Монета» (человекочитаемое имя)
и «Цена(USD)».
- Кнопка «Обновить
курсы» выполняет
повторный
запрос
к
API
и
обновляет
таблицу.
- При
ошибке
сети
или
API
выводится
диалоговое
окно
с
сообщением.
- Если
валюта
отсутствует
в
ответе, отображается «Н / Д».

## 3. Нефункциональные требования
- Интерфейс
на
русском 
языке.
- Окно
фиксированного
размера(420×380), без
изменения
размеров.
- Запрос
к
API
выполняется
с
таймаутом
10
секунд.
- Не
требуется
авторизация(используется
публичный
Demo
API
CoinGecko).

## 4. Используемый API
- Эндпоинт: `GET
https: // api.coingecko.com / api / v3 / simple / price
`
- Параметры: `ids`(список
id
монет
через
запятую), `vs_currencies = usd
`.
